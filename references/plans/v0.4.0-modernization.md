## Phase 2 — Tool Modernization (per tool)

Each tool follows the same migration pattern:

```
Before:                          After:
─────────────────────────────    ─────────────────────────────
def tool_name(args):             def main(arg1, arg2, ...):
    x = args.x                       # business logic only
    ...                              ...

def add_subparser(subparsers):   app = typer.Typer()
    subparsers.add_parser(...)
    ...                          @app.command()
                                 def cli(arg1: Annotated[...]):
                                     main(arg1, ...)
```

## Testing Strategy

| Test type | Location | Scheduler |
|---|---|---|
| Unit (pure logic) | `tests/test_*.py` | synchronous |
| Tool integration (synthetic audio) | `tests/test_tools_*.py` | synchronous |
| CLI smoke tests | `tests/test_cli.py` | synchronous |
| Full pipeline (real files) | manual / CI with fixtures | processes |

Synthetic audio fixtures: generate 5-second 44.1kHz mono WAV files with `numpy` + `scipy.io.wavfile` — no real recordings needed for unit/integration tests.
